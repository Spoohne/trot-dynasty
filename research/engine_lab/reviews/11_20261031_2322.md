## Astra

## 1. Fix the training/deployment mismatch before changing the model family

**Code findings—not hypotheses:**

- **Randomized horses do not use the deployed continuation policy.** `instr["aim"]` makes `h.scores={}`, disabling periodic score-based switching, although event switches still occur. You train on “forced initial aim + event rules,” then deploy “chosen initial aim + event rules + rescoring.”
- **Midrace scoring is not state valuation.** `drive_check` reuses pre-race scores plus gap/lane penalties. It does not value current energy, pace, remaining distance, available cover or actual rival commitments. It also stops checking once `h.moving`.
- **“Frozen” is not frozen.** `start_aim` overrides the selected opening only *after* best-response passes. Those passes still recompute rival aims and scores, potentially describing a different opening from the one actually executed.
- **The five aims are mostly gap/timing presets.** For example, “first-over” can tuck onto the rail before moving. Verify achieved trips before concluding an aim is intrinsically inferior.

**Reject:** “the early-speed result isolates the planner’s opening choice.” It demonstrates a harmful effect in the complete replanning implementation; the current frozen comparison does not locate it cleanly.

## 2. H14 is plausible, but regression \(r^2\) is not the diagnosis

**Structural problems:**

- Random exploration is useful, but **random-row selection does not make the whole fit unbiased**. Rivals respond to the randomized aim; recorded crowding is consequently partly an outcome of that intervention. Deployment evaluates alternative aims while largely holding that crowding description fixed.
- Same-aim counts omit important **cross-aim interactions**: following needs a useful horse ahead, while top/pocket competition affects several aims simultaneously.
- Pooling rounds mixes different opponent policies and continuation behavior. It can stabilize coefficients while averaging incompatible situations.
- Three quickest-first passes are an **order-dependent heuristic**, not demonstrated convergence to a best response. Increasing early speed can change both physical ability and planning priority.
- Expected “lengths behind the winner” is not expected placing or winning probability. Every win receives zero loss; a safe second can score better than a volatile winning chance. The target is usable only if that is the intended utility.

**Reject:** “low \(r^2\) proves linear scoring cannot work.” Evaluate **held-out action regret**—how much performance the selected aim loses versus alternatives in the same state. Ranking loss alone will not repair missing state, policy mismatch or poor action execution.

## 3. Separate post effects cheaply—and audit the external benchmark

Use **20 fixed fields, eight cyclic post rotations**, breaks off, DT 1/16:

1. **Balanced preassigned aims**, carried with horse identity; no learned switching.
2. **Current learned driver** on the same rotations.

Record first-turn position, time exposed/wide, extra ground, pocket acquisition, exit delay and finish time.

**Interpretation:**
- Strong inside advantage in both → investigate geometry and low-level trip execution.
- Large additional advantage under learned choices → driver amplification.
- Both can contribute; do not subtract them as independent causal shares.

For the worst few cases, repeat with a longer run to the first bend, then with pocket shelter disabled—**one diagnostic intervention at a time**, not proposed production rules.

**Benchmark correction:** Rideau-Carleton is a **five-eighths-mile oval**; “mile races” describes race distance. Its quoted post percentages also sum above 100%, indicating they are not win shares from a uniform eight-horse-field sample. Recheck field sizes, denominators and dates before using these as mile-track hard gates. The 71% result warrants investigation, but those bands do not validate its exact target.

## 4. Replacement: feasible actions plus counterfactual value learning

I recommend **feasibility checks + a small state-action value model**, retaining Patrick’s five aims, best-response passes, checks, limits and hysteresis.

- Generate **paired counterfactual continuations offline**: clone one state, try each feasible aim, use the same opponent policy and continuation rules in every arm.
- Include current geometry, energy, speed, remaining distance, accessible cover and rival commitments—not just bars/post.
- Fit a small regularized tree ensemble or interaction model to the chosen finish utility. Split validation by complete races/world states.
- Keep pre-gate passes, but test order sensitivity, cycles and residual improvement opportunities. Midrace, score the **current snapshot**, then apply hysteresis.
- Use short rollouts only where feasibility/value is uncertain; they need a terminal value model or will overvalue immediate position. Benchmark median/p95 runtime for hundreds of races rather than assuming cost.

**Smallest next experiment:** 20 fields × eight subjects × five opening aims, opponents held to one declared policy and identical continuation rules. Compare predicted rankings with realized outcomes.

If first-over/follow sometimes win that comparison but are never selected, fix the scorer. If they never help even in deliberately favorable cover/pressure cases, fix their execution or the engine—not their regression coefficients.
